# Published findings — directory guide

This directory contains **only** case studies cleared for public disclosure. It intentionally starts empty.

## Naming convention

Use one folder per finding:

~~~text
YYYY/short-descriptive-slug/README.md
YYYY/short-descriptive-slug/evidence/
~~~

Example folder names (not real findings):

- \`2026/horizontal-authorization-check/\`
- \`2026/session-state-invalidation/\`

The public index at [Bug Bounty & VDP Findings](../README.md) is the entry point. Add an index row only when the sanitized case study itself is ready to publish.

Start with the [finding template](../FINDING_TEMPLATE.md) and complete the [publication checklist](../PUBLICATION_CHECKLIST.md). Never put private drafts in this public repository, including on temporary branches.
